# Atlore Wiki

Welcome to the Atlore documentation. Atlore is a realtime tabletop RPG campaign manager built around a collaborative, Obsidian-style knowledge graph.

## Choose your path

### I want to use Atlore

1. Start with [Getting Started](https://github.com/jellesiderius/atlore/wiki/Getting-Started).
2. Learn where everything lives in the [Interface Overview](https://github.com/jellesiderius/atlore/wiki/Interface-Overview).
3. Build your world with [Nodes and Graph](https://github.com/jellesiderius/atlore/wiki/Nodes-and-Graph).
4. Record your game using [Sessions and Collaboration](https://github.com/jellesiderius/atlore/wiki/Sessions-and-Collaboration).
5. Add maps using [Maps and Media](https://github.com/jellesiderius/atlore/wiki/Maps-and-Media).

### I manage a campaign

- Configure members and player access in [Campaigns and Permissions](https://github.com/jellesiderius/atlore/wiki/Campaigns-and-Permissions).
- Change your profile, password, language, or theme in [Account and Preferences](https://github.com/jellesiderius/atlore/wiki/Account-and-Preferences).

### I want to run my own Atlore server

1. Follow [Self-hosting and Configuration](https://github.com/jellesiderius/atlore/wiki/Self-hosting-and-Configuration).
2. Keep [Troubleshooting](https://github.com/jellesiderius/atlore/wiki/Troubleshooting) nearby.
3. Read the repository's [Contributing guide](https://github.com/jellesiderius/atlore/blob/main/CONTRIBUTING.md) before changing the code.

## Main concepts

- **Campaign:** the complete shared world, its members, permissions, graph, sessions, and maps.
- **Node:** a person, place, faction, quest, item, monster, piece of lore, or another world entity.
- **Relationship:** a graph connection between two nodes.
- **Session:** the shared account of what happened at the table.
- **Personal notes:** private text visible only to its author.
- **Atlas:** the campaign map and any maps attached to place nodes.

Atlore supports Dutch and English. Dutch is the initial language; each user can change this from the account menu.
