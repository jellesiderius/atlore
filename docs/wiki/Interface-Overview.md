# Interface Overview

Atlore keeps world navigation on the left, the current view in the centre, and account controls in the header. On mobile, the main navigation moves to the bottom of the screen.

## Main navigation

| View        | Purpose                                                            |
| ----------- | ------------------------------------------------------------------ |
| **Graph**   | Explore nodes and relationships as an interactive knowledge graph. |
| **Session** | Create and edit shared session reports and private session notes.  |
| **Story**   | Read all non-deleted sessions as one continuous campaign story.    |
| **Map**     | View campaign and place maps and manage node markers.              |

Browser Back and Forward restore the active view, panel, session, node, node tab, and campaign-settings tab through the URL.

## Explorer panel

The Explorer has four tabs:

- **Explorer:** nodes grouped by type. Click a node to centre it in the graph; click it again to open its dossier.
- **Recent:** nodes opened during the current visit.
- **Search:** search node names, summaries, and other indexed text.
- **Settings:** trash, graph forces, display settings, campaign settings, and custom node types.

Use the panel toggle in the workspace header to hide or show the Explorer. The **+** button creates a node when your campaign permissions allow it.

## Keyboard and mouse controls

- `Ctrl+K` or `Cmd+K`: open the global search palette.
- `Escape`: close the current popup or context menu.
- Right-click a graph node, Explorer node, text-linked node, or map marker to open its context menu.
- Double-click a graph node to open its dossier.
- Double-click empty graph space to create a node at that position.
- Use the mouse wheel or trackpad to zoom the graph and atlas.
- Drag empty graph or atlas space to pan.

## Account menu

The round account button is available on the campaign overview. It contains:

- profile name, email address, and colour;
- password change;
- dark or light appearance;
- Dutch or English language;
- sign out.

See [Account and Preferences](https://github.com/jellesiderius/atlore/wiki/Account-and-Preferences) for details.
